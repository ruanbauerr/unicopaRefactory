# 🏆 UnicopaRefactory

Aplicativo mobile desenvolvido em **React Native**, com tema voltado à Copa do Mundo, integrado a um banco de dados **Supabase (SQL)**.

## 📱 Sobre o projeto


App para acompanhar jogos e informações da Copa do Mundo, com dados de partidas importados e organizados em um banco relacional.

## ✨ Funcionalidades

- Exibição de partidas com formatação de datas
- Mapeamento de bandeiras dos países/seleções
- Importação de dados de partidas da Copa do Mundo FIFA 2026 para o Supabase


## 🛠️ Tecnologias

- React Native
- Expo
- Supabase (PostgreSQL)
- SQL

## 🚀 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/ruanbauerr/unicopaRefactory.git

# Entre na pasta
cd unicopaRefactory

# Instale as dependências
npm install

# Rode o projeto
npx expo start
```
